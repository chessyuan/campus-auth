# 校园网自动认证 v1.8.5 · 设置精简和强制账号水印修订

日期：2026-10-12
状态：**候选测试版**（已通过 PC 构建、静态回归和签名验证；尚未完成手机实机/校园网现场验证）。

## 实际改动
- 首页把旧“低可见度模式”重命名为**隐藏后台**。该开关确实控制后台策略：开启则停用长期前台服务、采用系统 JobScheduler，并从最近任务中排除；关闭则采用持续 Wi-Fi 前台监控，可能在系统运行应用列表显示。**Android 不允许普通应用保证彻底从系统所有后台活动记录消失**。隐藏模式的任务调度可能延后。
- 删除独立“最近任务隐藏”开关，避免两开关相互矛盾；保留一个一键控制。
- 运行保障保留三行均可点击：账号与自动认证（**必选**，直接滚动到账号输入）；运行状态（点击请求恢复/调度检查）；电池不受限制（**建议**，直接打开可用的系统电池豁免申请，失败依次回退至电池优化列表和应用详情）。
- **彻底取消可选通知模块**：界面里无通知使用权、无普通通知权限；AndroidManifest 不再声明 POST_NOTIFICATIONS，不再注册通知读取监听服务。后台隐藏模式不再依赖通知事件，仅由 JobScheduler 与前台手动检查工作。
- 原“姓名水印”已彻底从界面、设置选项和读取逻辑删除。水印固定显示**当前加密存储的校园网登录账号**（对应运营商后缀），不可手动修改或关闭。未配置账号显示“校园网账号未配置”；保存或恢复界面后自动更新；升级后清除旧 watermark_name 偏好。
- 动态极光、四种主题、颜色算法、22dp 卡片、手机底栏和平板双栏不变。关闭动态极光仍展示必需的校园网账号水印。

## Android 通用设置跳转
优先采用 Android 官方 Settings.ACTION_REQUEST_IGNORE_BATTERY_OPTIMIZATIONS（带本应用包名）；失败则 ACTION_IGNORE_BATTERY_OPTIMIZATION_SETTINGS，最终退回 ACTION_APPLICATION_DETAILS_SETTINGS。所有设置操作只启动系统设置，由用户决定是否授权，不修改系统配置。
各 Android 品牌具有独立电池省电策略，不能通过单一公开标准 API 保证定位厂商定制的“无限制”页面；无法自动突破系统保活限制。
