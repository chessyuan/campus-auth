## 主要功能

- **自动认证**：保存校园网账号、密码和运营商后，连接支持的校园网时自动检查登录。
- **隐藏后台**：用户可启用不常驻前台服务的系统调度方式，并隐藏最近任务卡片；Android 仍可能推迟任务，不能保证永远驻留或完全从系统后台管理中消失。
- **两种运行策略**：隐藏后台（省心、后台调度可能延迟）；关闭隐藏后台后采用前台持续监控（认证更及时，可能显示在系统后台活动列表）。
- **One UI 风格界面**：动态极光背景、深色/浅色/AMOLED 纯黑/系统动态配色；手机单栏和平板双栏适配。
- **简洁设置**：账号与认证状态、后台运行状态、电池优化入口；不索取非必需的通知读取权限。
- **账号安全**：账号密码存储在应用私有空间，以 Android Keystore 的 AES-GCM 密钥加密；不会上传到作者服务器。
- **账号水印**：背景文字自动读取设备上保存的校园网登录账号，不能在外观菜单中另行修改。请留意屏幕分享或截图时账号可能可见。

## 安装与使用

1. 从 **Releases** 下载 v1.8.6 APK 并安装。已有相同签名的旧版，可尝试直接覆盖升级，不必卸载丢失设置。
2. 在应用里选择运营商，填写自己的校园网账号和密码，点击 **保存配置并启用**。
3. 根据需要选择 **隐藏后台**；点击 **电池不受限制** 可以打开系统对应设置入口，减少后台调度受限制的概率。
4. 连接支持的校园 Wi-Fi，在首页查看认证及最近运行记录。

**适配范围**：目前主要针对南京医科大学校园网络中使用的相关门户认证流程，不承诺适配其他高校。不同 Android 手机厂商的电池管理界面、Doze 和系统调度机制可能导致任务延迟。本版通过本地编译、签名及静态回归检查，尚未在所有手机品牌和实际校园 Wi-Fi 环境中完成全覆盖测试。

`android/src/` 为原生 Android Java 源码，`android/AndroidManifest.xml` 为应用配置，`scripts/` 为本地构建和回归脚本。构建需 Android SDK、Java 和**自己的本地签名密钥**。仓库和正式版源码压缩包**不包含**签名密钥、签名密码、真实账号或会话凭据；发布用的正式签名证书指纹见 Release Notes。
